1. 30초 워크플로우

  1. 프리셋 선택 — 만들려는 이펙트에 가장 가까운 것을 고릅니다. 권장 수치가 슬라이더에 자동으로 채워집니다.
  2. 슬라이더 튜닝 — 값을 바꾸면 미리보기가 즉시 다시 계산됩니다. 마음에 안 들면 🎲 랜덤 시드로 다른 변주를 뽑아 보세요.
  3. 내보내기 — PNG 시트 내보내기로 1열 스트립을 저장하고, Lua 로더 스니펫 복사로 LÖVE2D 코드를 받습니다.
미리보기 = 결과물. 미리보기는 내보낼 프레임을 그대로 구워서 재생합니다. 화면에 보이는 프레임이 곧 PNG에 들어가는 프레임이며, 시드가 같으면 결과도 항상 같습니다.

2. 두 가지 렌더링 방식

프리셋은 성격이 완전히 다른 두 계열로 나뉩니다. 이걸 알면 슬라이더가 왜 그렇게 반응하는지 이해됩니다.

방식원리특징
파티클 낱개 입자를 방출해 물리(중력·감쇠)로 움직임 흩어지고 튀는 느낌. 폭발·스파크·연기에 적합
면 기반 도형(화염 콘·링)을 픽셀 단위로 직접 채움 덩어리진 실루엣. 엔진 화염·에너지 폭발에 적합
면 기반 프리셋은 particleCount를 0으로 내려 스파크를 완전히 없앨 수 있습니다 — 레퍼런스 아트처럼 깨끗한 플룸이 됩니다. 반대로 파티클 계열을 0으로 내리면 화면이 비어버립니다.

4. 파라미터 사전

같은 슬라이더라도 방식에 따라 의미가 달라집니다. 오른쪽 열을 꼭 확인하세요.

파라미터범위파티클에서면 기반에서
particleCount0–128 방출 입자 수. 많을수록 조밀 보조 스파크 수. 0 = 스파크 없음
burstSpeed0.5–8 초기 속도. 클수록 멀리 퍼짐 크기 결정. 화염=길이, Ring=최대 반경
spreadAngle10–360° 방출 부채꼴 각도. 360=전방위 노즐 폭. 클수록 두꺼운 플룸
gravity-0.2–0.5 낙하 가속. 음수면 위로 떠오름 스파크에만 적용
drag0.8–1.0 공기저항. 낮을수록 급격히 감속 스파크에만 적용
lifeFrames2–32 입자 수명(프레임) 지속형=루프 주기 / Ring=팽창 시간
flashFrames0–3 시작 시 중앙 흰 원의 지속 프레임 수. 0=없음. 타격감을 만드는 핵심
smokeAmount0–1 잔연기 양. 파티클이 열을 주입하고 셀룰러 오토마타로 위로 번짐. 0=연기 없음
frameCount2–48 내보낼 프레임 수 = 미리보기 프레임 수. 시트 가로 길이를 결정

드롭다운 / 기타

항목설명
캔버스 크기32 / 48 / 64 / 96 / 128 px. 스프라이트 한 장의 크기. 잡몹 32–48, 일반 64, 보스 96–128
이펙트 크기0.25~4배. 이펙트 자체를 균일하게 확대·축소합니다. 속도·입자 크기·화염 길이·링 반경·플래시가 모두 함께 스케일되어 형태는 그대로 두고 크기만 바뀝니다. 튜닝을 다시 하지 않고 대형 버전을 뽑을 때 쓰세요. 캔버스 크기와 짝지어 올리는 것이 요령이며, 프리셋을 바꿔도 유지됩니다
방향분사·방출 방향. 프리셋 기본 또는 상하좌우 지정. 종스크롤 슈팅은 ↓, 횡스크롤은 ←
재생 속도1~30 fps. 미리보기 재생 속도이자 Lua 스니펫에 기록되는 값. PNG 자체에는 속도 정보가 없으므로 게임에서 이 값을 쓰게 됩니다. 픽셀 이펙트는 8~15fps가 무난하고, 빠른 타격감은 20fps 이상으로 올립니다
시드난수 씨앗. 같은 시드 = 같은 결과. 모양이 마음에 안 들면 랜덤으로 다시 뽑기
미리보기 클릭클릭한 지점이 이펙트 발생 위치가 됩니다(중앙이 아닌 곳에서 터뜨릴 때)

5. 팔레트

파티클은 색을 부드럽게 섞지 않고 수명에 따라 램프 단계를 이산적으로 건너뜁니다. 이게 픽셀아트 룩의 핵심입니다.

팔레트느낌추천 용도
Classic Fire흰→노랑→주황→빨강→암갈일반 폭발, 화염 (기본값)
NES제한 팔레트, 채도 낮음레트로 8비트 룩
C64거친 대비, 특유의 색조레트로 컴퓨터 감성
Plasma흰→하늘→파랑→보라에너지 무기, EMP, 마법
Toxic흰→연두→녹색독·산성·바이오 이펙트
Afterburner흰→시안→주황→적전투기 엔진 화염
Ion순수 청백 플라즈마SF 함선 엔진, 이온 추진
Custom6칸 직접 지정게임 고유 팔레트에 맞출 때

Custom을 고르면 색상 피커 6칸이 나타납니다. 왼쪽이 가장 밝은 코어, 오른쪽이 소멸 직전 순서로 넣으세요.

팔레트 직접 만들기

  • 기본 팔레트에서 출발하기 — 현재 팔레트를 Custom으로 복사를 누르면 지금 팔레트의 6색이 Custom 칸으로 들어옵니다. 처음부터 고를 필요 없이 몇 칸만 손보면 됩니다.
  • hex로 주고받기 — 외부 팔레트에서 복사한 코드를 입력란에 붙여넣고 hex 적용을 누르면 반영됩니다. 쉼표·공백 어떤 구분자든 인식하고 #RGB 축약형도 됩니다. hex 복사로 현재 색을 가져갈 수도 있습니다.
  • 만든 팔레트는 JSON 프리셋에 함께 저장되므로 게임 고유 팔레트를 팀과 공유하기 좋습니다.

5-2. 알파 / 페이드

이펙트가 뚝 끊기지 않고 잦아들게 하거나, 연기·글로우만 은은하게 비치도록 만드는 기능입니다.

항목설명
알파 방식디더는 알파를 Bayer 패턴의 픽셀 솎아내기로 표현합니다 — 모든 픽셀이 불투명하게 남아 팔레트가 보존되는 고전 픽셀아트 방식입니다. 실제 알파는 반투명 값을 그대로 기록해 부드럽지만 배경과 섞입니다. 픽셀 룩을 지키려면 디더를 권합니다
꼬리 페이드0~1. 애니메이션 마지막 구간을 서서히 사라지게 합니다. 0.5면 후반 절반에 걸쳐 사라집니다
램프 색별 알파6칸이 램프의 각 색에 대응합니다(바로 위 미니 램프와 같은 순서). 어두운 쪽만 내리면 밝은 코어는 또렷하고 연기만 반투명해집니다. 숫자는 불투명도 %
알파를 쓰려면 '알파 방식'을 먼저 켜야 합니다 — 꺼져 있으면 페이드와 색별 알파가 모두 무시됩니다.

5-3. 포스트 프로세스 (셰이더)

확대 전의 저해상도 버퍼에 거는 픽셀 단위 후처리입니다. 그래서 결과가 픽셀 그리드에 정확히 정렬되고, 새로 칠하는 색도 전부 현재 팔레트 램프 안에서만 고릅니다.

패스하는 일잘 듣는 곳
AA 블러가 아닌 수동 AA. ①바깥 실루엣의 오목한 계단을 중간 톤으로 메우고, ②안쪽 색 밴드가 급하게 튀는 경계에 중간 단계를 끼워 넣습니다. 0.75 이상이면 밝은 코어의 대각 계단까지 잇지만 실루엣이 두꺼워집니다 곡선이 많은 Ring Blast는 ①이, 얇은 화염 계열은 ②가 대부분의 차이를 만듭니다
Glow밝은 코어(램프 0~1) 둘레로 어두운 색이 1~3px 번집니다SF 함선 엔진의 빛무리. 밝은 코어가 없으면 번지지 않습니다
Dither색 밴드 경계를 4×4 Bayer 체커로 섞습니다연기, 넓게 퍼지는 분사
Outline실루엣 바깥에 테두리를 한 겹 두릅니다밝은 배경에서 이펙트가 묻힐 때
AA가 안 먹는 것 같다면 형상이 너무 작아서일 수 있습니다. 화염 한 줄기는 50픽셀 남짓이라 손볼 계단 자체가 몇 개 없습니다. 이펙트 크기를 키우면 AA가 다룰 면이 늘어 효과가 확실해집니다. 글로우를 함께 켜 두면 AA가 메운 픽셀이 빛무리에 묻혀 잘 안 보이기도 하니, 조정할 때는 글로우를 잠시 0으로 두고 보세요.

6. 내보내기

가로 1열 스트립 PNG로 저장됩니다. 크기는 frameCount × 캔버스크기 (예: 8프레임 64px → 512×64), 배경은 투명입니다.

파일명 규칙: {프리셋}_{크기}px_{프레임수}f_seed{시드}.png — 시드가 파일명에 들어가므로 나중에 같은 이펙트를 그대로 재현할 수 있습니다.

JSON 프리셋

JSON 저장으로 현재 슬라이더 값 전체를 파일로 남기고, JSON 불러오기로 복원합니다. 자주 쓰는 설정은 presets/ 폴더에 모아두면 팀에서 공유하기 좋습니다.

7. LÖVE2D 연동

Lua 로더 스니펫 복사 버튼을 누르면 현재 설정에 맞는 코드가 클립보드에 복사됩니다.

local Anim = require("explosion")
local fx = Anim.load("explosion_64px_8f_seed1234.png", 64, 64)

-- 그리기
local i = math.floor(timer * fx.fps) % #fx.quads + 1
love.graphics.draw(fx.img, fx.quads[i], x, y, 0, 1, 1, 32, 32)
필수: img:setFilter("nearest", "nearest") — 스니펫에 포함되어 있습니다. 이게 빠지면 확대할 때 픽셀이 뭉개져 애써 만든 픽셀아트 룩이 사라집니다.

노즐이 여러 개인 함선: 시트는 하나만 뽑고 각 노즐 좌표에 같은 애니메이션을 그리되, 노즐마다 프레임 인덱스를 1–2씩 어긋나게 주면 기계적인 동기화가 사라져 자연스러워집니다.

9. 문제 해결

증상원인 / 해결
화면이 비어 있음파티클 계열에서 particleCount 0. 값을 올리거나 면 기반 프리셋 사용

모양이 마음에 안 듦수치를 만지기 전에 🎲 랜덤 시드를 서너 번 눌러보기 — 같은 설정도 시드마다 인상이 크게 다릅니다

10. pixelfx 이펙트 (244종)

pixelfx의 이펙트가 프리셋 목록 아래 pixelfx · 카테고리 묶음으로 들어 있습니다(불·폭발·물·얼음·번개·근접·마법·상태이상·날씨·UI·픽업·크리처 등). 고르면 이펙트를 그리는 코드는 pixelfx가 맡고, 팔레트 · 알파 · 후처리 · 시드 · 내보내기는 이 에디터의 것을 그대로 씁니다.

항목pixelfx에서
캔버스이펙트 원래 크기(예: 128×128, 300×240)로 고정. 캔버스 크기·이펙트 크기 슬라이더는 꺼집니다
팔레트pixelfx 원본 색 = 원래 색 그대로. 다른 팔레트를 고르면 밝기 순으로 6색에 다시 칠하고, 반투명은 디더로 바꿔 6색만 남깁니다
pixelfx 옵션이펙트마다 다른 옵션(색 램프, 높이, 크기 등)이 자동으로 나타납니다. 옵션 기본값으로로 되돌립니다
라이트발광(빛) 레이어 합성. 끄면 실루엣이 또렷해져 외곽선·AA가 깔끔합니다
캐릭터화상·빙결 같은 캐릭터용 이펙트에서 스탠드인 캐릭터를 함께 그립니다. 켜면 시트에도 들어갑니다
frameCount루프는 한 주기를 균등 분할(이음새 없음), 1회성은 처음~끝을 포함해 나눕니다. 고르면 길이에 맞춰 자동 설정
부품 조절이 이펙트가 쓰는 파티클·조명·파편·잔불을 켜고 끄거나 개수·속도·수명·크기 배율을 바꿉니다 (11장 끝 참고). 구성 카드의 칩을 눌러도 열립니다
빛 세기빛 레이어 전체의 세기 배율 (0~3)
구성 카드미리보기 아래에 이 이펙트의 부품 · 대표 프레임 · 활동 그래프 (11장 참고). 접기로 숨기면 미리보기가 커집니다
방향 / 클릭← = 좌우 반전, ↓·↑ = 90° 회전. 미리보기를 클릭하면 이펙트 기준점이 그 자리로 옮겨집니다
pixelfx 이펙트를 고른 상태에서 JSON 저장을 하면 바꾼 pixelfx 옵션까지 함께 저장됩니다. pixelfx는 MIT 라이선스이며 고지 전문은 vendor/pixelfx.LICENSE에 있습니다. pixelfx를 새 버전으로 바꾸려면 node tools/build-pixelfx.mjs <pixelfx 경로>로 다시 묶으세요.

11. pixelfx 이펙트의 구성과 조립

pixelfx 이펙트는 이 에디터의 기본 프리셋처럼 슬라이더 몇 개로 움직이는 시뮬레이터 하나가 아닙니다. 이펙트마다 부품을 골라 시간표에 맞춰 배치한 레시피 파일입니다. 그래서 10장의 pixelfx 옵션에는 색·크기 같은 몇 가지만 보이고 부품별 슬라이더는 없습니다. 이 장은 그 레시피가 어떻게 생겼는지, 처음 만드는 사람 기준으로 설명합니다. (출처: pixelfx의 docs/AUTHORING.md와 기준 예제 explosions/small-explosion.js)

지금 고른 이펙트로 보기: pixelfx 이펙트를 고르면 미리보기 아래 이 이펙트의 구성 카드에 그 이펙트의 그리기 방식·레이어·캐릭터 연기 여부, 쓰인 부품(아래 ③의 이름 그대로, 마우스를 올리면 설명), 시간 순서대로 본 대표 프레임 8장과 활동 그래프가 나옵니다. 썸네일이나 그래프를 누르면 미리보기가 그 순간으로 이동합니다. 합성 이펙트(moves)는 구성 이펙트를 눌러 하나씩 열어 볼 수 있습니다. 점선 칩은 같은 카테고리의 공용 도우미(_lib.js)를 거쳐 쓰이는 부품입니다. 부품 목록은 소스를 읽어 뽑은 것이라 "코드에 등장하는 부품"이며, 실제로 몇 개가 뿌려지는지는 아닙니다.

전체 구조: 5개 층

이펙트 파일 1개 (예: explosions/small-explosion.js)

├─ ② 그리기 방식         순수형 또는 시뮬레이션형 중 하나

└─ ⑤ (선택) 연기와 합성   act(캐릭터 동작), chain(이펙트끼리 잇기)

④ 출력 칸: 버퍼 2개 × 레이어 2개

  • 색 버퍼 — 실제 픽셀. 불투명·디더·반투명 모두 가능.
  • 빛 버퍼 — 위에 더해지는 발광. 뜨거운 것이 뜨거워 보이는 이유입니다. 10장의 라이트 체크박스가 이것을 켜고 끕니다.
  • 뒤 레이어 — 캐릭터 뒤에 그릴 것 (바닥 링의 먼 쪽 절반, 그을음 등).
  • 앞 레이어 — 캐릭터 앞에 그릴 것 (나머지 전부).

⑤ (선택) 캐릭터 연기와 합성

  • act — 이펙트에 맞춘 캐릭터 동작: 예비 동작 → 공격 → 타격 순간 멈춤·흔들림 → 회복.
  • 캐릭터 이펙트 — 화상·빙결처럼 캐릭터 실루엣의 색을 바꾸거나 외곽선을 두름. 10장의 캐릭터 체크박스.
  • chain (moves 카테고리) — 이펙트끼리 잇기. 예: 충전 → 화염구 비행 → 폭발.

조립 예시: 폭발을 분해하면

조립 원칙은 단계로 나눈 안무입니다: 충전 → 방출 → 확산 → 유지 → 붕괴 → 긴 잔향.

단계시점쓰인 부품
방출0~0.08초흰 원 플래시 0.06초, 흰 조명 0.08초
충격0~0.5초공중 링 2개(0.34·0.22초), 바닥 band 링 0.5초 — 먼 쪽 절반은 뒤, 가까운 쪽은 앞 레이어
확산0~1초FIRE 33개(절반가량은 식어 연기로), SPARK 80개, BRAND 9~14개

잔향~5.4초연기 기둥이 걷히고, 바닥 그을음이 하얗게 달았다가 검게 식으며 사라짐

한 프레임을 그리는 순서: 뒤 레이어(그을음 → 뒤쪽 파티클 → 잔불 → 바닥 링 먼 쪽) → 캐릭터 → 앞 레이어(바닥 링 가까운 쪽 → 돌 → 앞쪽 파티클 → 플래시 → 공중 링 → 조명).

이 에디터의 기본 Explosion은 파티클 1종 + 플래시 + 연기를 슬라이더 9개로 조절합니다. pixelfx 폭발은 부품 10여 종 수백 개를 단계별로 직접 배치한 것이라, 공통 슬라이더로 쪼개 놓지 않았습니다.

처음 만드는 사람을 위한 조립 순서

  1. 한 줄로 말하기 — "바닥의 수류탄이 흰빛으로 터지고, 돌이 튀고, 연기 기둥이 남는다".
  2. 명세서 쓰기 — 크기, 기준점(충돌 지점), 길이, 루프 여부, 색 옵션.
  3. 방식 고르기 — 반복되면 순수형, 한 번 터지고 끝나면 시뮬레이션형.
  4. 단계별 부품 배치 — "언제, 무엇을, 몇 개" 뿌릴지 위 표처럼 적기. 빠르게 터지고 천천히 사라지게.
  5. 레이어와 빛 나누기 — 캐릭터 뒤/앞을 나누고, 뜨거운 곳에는 빛을 겹치기.
  6. 렌더해서 보고 고치기 — 가장 나쁜 점 하나를 고치고 다시 렌더. 최소 3번.

가장 작은 시뮬레이션형 예제 (pixelfx 문서의 "Spark pop"에 주석을 단 것):

export function create(o) {
  const C = fit(o.palette, 7), R = new Rng(o.seed);       // 색 램프 7단계, 시드 고정 난수
  const ps = new Particles({ rng: R, ground: () => 0 });   // 파티클 상자 (바닥 y=0)
  const lights = new Lights();
  lights.add(0, -12, 40, C[4], 0.7, 0.4);                  // 반경 40 조명, 0.4초 동안 꺼짐
  for (let i = 0; i < 40; i++) {                           // 스파크 40개를 사방으로
    const a = R.range(0, Math.PI * 2), sp = R.range(80, 260);
    ps.spawn(P.SPARK, 0, -12, Math.cos(a) * sp, Math.sin(a) * sp - 60, R.range(0.2, 0.6));
  }
  let t = 0;
  return {
    update(dt) { t += dt; ps.update(dt); lights.update(dt); },   // 물리 진행
    draw(p) {
      if (t < 0.12) sparkle(p, 0, -12, 9 * (1 - t / 0.12), C[5], C[3]);  // 처음 0.12초 섬광
      ps.draw(p); lights.draw(p);
    },
  };
}

에디터에서 부품 조절하기

오른쪽 부품 조절 묶음은 지금 이펙트가 쓰는 부품 중 공통으로 조절할 수 있는 것만 보여 줍니다 (구성 카드의 칩을 눌러도 해당 부품이 열립니다). 부품 이름을 누르면 배율 슬라이더가 펼쳐집니다.

부품조절 항목
파티클 12종켜기/끄기, 개수 ×0~3, 속도 ×0.25~3, 수명 ×0.25~3, 크기 ×0.25~3
Lights 조명켜기/끄기, 밝기 ×0~3, 반경 ×0.25~3
Bits 파편켜기/끄기, 개수, 속도, 수명
Blazes 잔불켜기/끄기, 개수, 수명, 세기
  • 되는 이펙트: 시뮬레이션형과, 그것을 이어 붙인 합성(moves). 순수형은 부품을 뿌리지 않고 시간으로 바로 계산해서 이 방식이 통하지 않습니다 — pixelfx 옵션과 빛 세기만 조절됩니다.
  • 안 되는 것: 링·셰이더·원처럼 도형으로 직접 그리는 부분(예: 뉴크의 버섯구름 몸통·기둥, 바닥 링). 이건 이펙트 코드에 옵션이 있어야 바뀝니다.
  • 개수를 바꾸면 남기거나 늘릴 입자를 시드로 뽑기 때문에, 같은 시드라도 모양이 원본과 조금 달라집니다. 같은 설정이면 결과는 항상 같습니다.
  • 불덩이가 식어 생기는 연기처럼 파티클이 스스로 만드는 파티클은 켜기/끄기와 개수만 따릅니다 (속도·수명·크기가 겹쳐 곱해지지 않게).
  • 부품 조절은 JSON 저장에 함께 저장되고, 내보내는 시트에도 그대로 들어갑니다.

좋아 보이게 하는 규칙

  • 면을 채우지 말고 1px 선·링·꼬리·스파크로 만들고, 밝기는 빛 버퍼에 맡깁니다.
  • 빛을 아끼지 않기 — 넓고 약한 빛 + 중심의 강한 빛 + 스파크마다 작은 빛.
  • 연기·먼지·김은 반투명하게 부풀며 옅어지게. 체크무늬 디더로 연기를 그리지 않습니다.
  • 스파크는 늘어나고 튀고, 파편은 구르다 멈추고, 불은 올라가며 식어 연기가 됩니다.
  • 타격은 0.3~0.8초로 짧게, 큰 이펙트는 2~4초 여운. 바닥 링은 납작한 타원, 먼 쪽 절반은 캐릭터 뒤.
