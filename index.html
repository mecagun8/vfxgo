1. 30초 워크플로우

  1. 프리셋 선택 — 만들려는 이펙트에 가장 가까운 것을 고릅니다. 권장 수치가 슬라이더에 자동으로 채워집니다.
  2. 슬라이더 튜닝 — 값을 바꾸면 미리보기가 즉시 다시 계산됩니다. 마음에 안 들면 🎲 랜덤 시드로 다른 변주를 뽑아 보세요.
  3. 내보내기 — PNG 시트 내보내기로 1열 스트립을 저장하고, Lua 로더 스니펫 복사로 LÖVE2D 코드를 받습니다.
미리보기 = 결과물. 미리보기는 내보낼 프레임을 그대로 구워서 재생합니다. 화면에 보이는 프레임이 곧 PNG에 들어가는 프레임이며, 시드가 같으면 결과도 항상 같습니다.

2. 두 가지 렌더링 방식

프리셋은 성격이 완전히 다른 두 계열로 나뉩니다. 이걸 알면 슬라이더가 왜 그렇게 반응하는지 이해됩니다.

방식원리특징
파티클 낱개 입자를 방출해 물리(중력·감쇠)로 움직임 흩어지고 튀는 느낌. 폭발·스파크·연기에 적합
면 기반 도형(화염 콘·링)을 픽셀 단위로 직접 채움 덩어리진 실루엣. 엔진 화염·에너지 폭발에 적합
면 기반 프리셋은 particleCount를 0으로 내려 스파크를 완전히 없앨 수 있습니다 — 레퍼런스 아트처럼 깨끗한 플룸이 됩니다. 반대로 파티클 계열을 0으로 내리면 화면이 비어버립니다.

4. 파라미터 사전

같은 슬라이더라도 방식에 따라 의미가 달라집니다. 오른쪽 열을 꼭 확인하세요.

파라미터범위파티클에서면 기반에서
particleCount0–128 방출 입자 수. 많을수록 조밀 보조 스파크 수. 0 = 스파크 없음
burstSpeed0.5–8 초기 속도. 클수록 멀리 퍼짐 크기 결정. 화염=길이, Ring=최대 반경
spreadAngle10–360° 방출 부채꼴 각도. 360=전방위 노즐 폭. 클수록 두꺼운 플룸
gravity-0.2–0.5 낙하 가속. 음수면 위로 떠오름 스파크에만 적용
drag0.8–1.0 공기저항. 낮을수록 급격히 감속 스파크에만 적용
lifeFrames2–32 입자 수명(프레임) 지속형=루프 주기 / Ring=팽창 시간
flashFrames0–3 시작 시 중앙 흰 원의 지속 프레임 수. 0=없음. 타격감을 만드는 핵심
smokeAmount0–1 잔연기 양. 파티클이 열을 주입하고 셀룰러 오토마타로 위로 번짐. 0=연기 없음
frameCount2–24 내보낼 프레임 수 = 미리보기 프레임 수. 시트 가로 길이를 결정

드롭다운 / 기타

항목설명
캔버스 크기32 / 48 / 64 / 96 / 128 px. 스프라이트 한 장의 크기. 잡몹 32–48, 일반 64, 보스 96–128
이펙트 크기0.25~4배. 이펙트 자체를 균일하게 확대·축소합니다. 속도·입자 크기·화염 길이·링 반경·플래시가 모두 함께 스케일되어 형태는 그대로 두고 크기만 바뀝니다. 튜닝을 다시 하지 않고 대형 버전을 뽑을 때 쓰세요. 캔버스 크기와 짝지어 올리는 것이 요령이며, 프리셋을 바꿔도 유지됩니다
방향분사·방출 방향. 프리셋 기본 또는 상하좌우 지정. 종스크롤 슈팅은 ↓, 횡스크롤은 ←
재생 속도1~30 fps. 미리보기 재생 속도이자 Lua 스니펫에 기록되는 값. PNG 자체에는 속도 정보가 없으므로 게임에서 이 값을 쓰게 됩니다. 픽셀 이펙트는 8~15fps가 무난하고, 빠른 타격감은 20fps 이상으로 올립니다
시드난수 씨앗. 같은 시드 = 같은 결과. 모양이 마음에 안 들면 랜덤으로 다시 뽑기
미리보기 클릭클릭한 지점이 이펙트 발생 위치가 됩니다(중앙이 아닌 곳에서 터뜨릴 때)

5. 팔레트

파티클은 색을 부드럽게 섞지 않고 수명에 따라 램프 단계를 이산적으로 건너뜁니다. 이게 픽셀아트 룩의 핵심입니다.

팔레트느낌추천 용도
Classic Fire흰→노랑→주황→빨강→암갈일반 폭발, 화염 (기본값)
NES제한 팔레트, 채도 낮음레트로 8비트 룩
C64거친 대비, 특유의 색조레트로 컴퓨터 감성
Plasma흰→하늘→파랑→보라에너지 무기, EMP, 마법
Toxic흰→연두→녹색독·산성·바이오 이펙트
Afterburner흰→시안→주황→적전투기 엔진 화염
Ion순수 청백 플라즈마SF 함선 엔진, 이온 추진
Custom6칸 직접 지정게임 고유 팔레트에 맞출 때

Custom을 고르면 색상 피커 6칸이 나타납니다. 왼쪽이 가장 밝은 코어, 오른쪽이 소멸 직전 순서로 넣으세요.

팔레트 직접 만들기

  • 기본 팔레트에서 출발하기 — 현재 팔레트를 Custom으로 복사를 누르면 지금 팔레트의 6색이 Custom 칸으로 들어옵니다. 처음부터 고를 필요 없이 몇 칸만 손보면 됩니다.
  • hex로 주고받기 — 외부 팔레트에서 복사한 코드를 입력란에 붙여넣고 hex 적용을 누르면 반영됩니다. 쉼표·공백 어떤 구분자든 인식하고 #RGB 축약형도 됩니다. hex 복사로 현재 색을 가져갈 수도 있습니다.
  • 만든 팔레트는 JSON 프리셋에 함께 저장되므로 게임 고유 팔레트를 팀과 공유하기 좋습니다.

5-2. 알파 / 페이드

이펙트가 뚝 끊기지 않고 잦아들게 하거나, 연기·글로우만 은은하게 비치도록 만드는 기능입니다.

항목설명
알파 방식디더는 알파를 Bayer 패턴의 픽셀 솎아내기로 표현합니다 — 모든 픽셀이 불투명하게 남아 팔레트가 보존되는 고전 픽셀아트 방식입니다. 실제 알파는 반투명 값을 그대로 기록해 부드럽지만 배경과 섞입니다. 픽셀 룩을 지키려면 디더를 권합니다
꼬리 페이드0~1. 애니메이션 마지막 구간을 서서히 사라지게 합니다. 0.5면 후반 절반에 걸쳐 사라집니다
램프 색별 알파6칸이 램프의 각 색에 대응합니다(바로 위 미니 램프와 같은 순서). 어두운 쪽만 내리면 밝은 코어는 또렷하고 연기만 반투명해집니다. 숫자는 불투명도 %
알파를 쓰려면 '알파 방식'을 먼저 켜야 합니다 — 꺼져 있으면 페이드와 색별 알파가 모두 무시됩니다.

5-3. 포스트 프로세스 (셰이더)

확대 전의 저해상도 버퍼에 거는 픽셀 단위 후처리입니다. 그래서 결과가 픽셀 그리드에 정확히 정렬되고, 새로 칠하는 색도 전부 현재 팔레트 램프 안에서만 고릅니다.

패스하는 일잘 듣는 곳
AA 블러가 아닌 수동 AA. ①바깥 실루엣의 오목한 계단을 중간 톤으로 메우고, ②안쪽 색 밴드가 급하게 튀는 경계에 중간 단계를 끼워 넣습니다. 0.75 이상이면 밝은 코어의 대각 계단까지 잇지만 실루엣이 두꺼워집니다 곡선이 많은 Ring Blast는 ①이, 얇은 화염 계열은 ②가 대부분의 차이를 만듭니다
Glow밝은 코어(램프 0~1) 둘레로 어두운 색이 1~3px 번집니다SF 함선 엔진의 빛무리. 밝은 코어가 없으면 번지지 않습니다
Dither색 밴드 경계를 4×4 Bayer 체커로 섞습니다연기, 넓게 퍼지는 분사
Outline실루엣 바깥에 테두리를 한 겹 두릅니다밝은 배경에서 이펙트가 묻힐 때
AA가 안 먹는 것 같다면 형상이 너무 작아서일 수 있습니다. 화염 한 줄기는 50픽셀 남짓이라 손볼 계단 자체가 몇 개 없습니다. 이펙트 크기를 키우면 AA가 다룰 면이 늘어 효과가 확실해집니다. 글로우를 함께 켜 두면 AA가 메운 픽셀이 빛무리에 묻혀 잘 안 보이기도 하니, 조정할 때는 글로우를 잠시 0으로 두고 보세요.

6. 내보내기

가로 1열 스트립 PNG로 저장됩니다. 크기는 frameCount × 캔버스크기 (예: 8프레임 64px → 512×64), 배경은 투명입니다.

파일명 규칙: {프리셋}_{크기}px_{프레임수}f_seed{시드}.png — 시드가 파일명에 들어가므로 나중에 같은 이펙트를 그대로 재현할 수 있습니다.

JSON 프리셋

JSON 저장으로 현재 슬라이더 값 전체를 파일로 남기고, JSON 불러오기로 복원합니다. 자주 쓰는 설정은 presets/ 폴더에 모아두면 팀에서 공유하기 좋습니다.

7. LÖVE2D 연동

Lua 로더 스니펫 복사 버튼을 누르면 현재 설정에 맞는 코드가 클립보드에 복사됩니다.

local Anim = require("explosion")
local fx = Anim.load("explosion_64px_8f_seed1234.png", 64, 64)

-- 그리기
local i = math.floor(timer * fx.fps) % #fx.quads + 1
love.graphics.draw(fx.img, fx.quads[i], x, y, 0, 1, 1, 32, 32)
필수: img:setFilter("nearest", "nearest") — 스니펫에 포함되어 있습니다. 이게 빠지면 확대할 때 픽셀이 뭉개져 애써 만든 픽셀아트 룩이 사라집니다.

노즐이 여러 개인 함선: 시트는 하나만 뽑고 각 노즐 좌표에 같은 애니메이션을 그리되, 노즐마다 프레임 인덱스를 1–2씩 어긋나게 주면 기계적인 동기화가 사라져 자연스러워집니다.

9. 문제 해결

증상원인 / 해결
화면이 비어 있음파티클 계열에서 particleCount 0. 값을 올리거나 면 기반 프리셋 사용
이펙트가 화면 밖으로 나감burstSpeed를 낮추거나 캔버스 크기를 키우기
루프가 뚝 끊김지속형(Thruster·Afterburner·Ion Trail·Hover Jet) 프리셋인지 확인. 1회성은 루프에 부적합
색이 뭉개져 보임게임 쪽에서 nearest 필터 누락. 또는 Custom 램프의 명도 차가 너무 작음
모양이 마음에 안 듦수치를 만지기 전에 🎲 랜덤 시드를 서너 번 눌러보기 — 같은 설정도 시드마다 인상이 크게 다릅니다
